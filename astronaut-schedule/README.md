# Astronaut Daily Schedule Organizer
Console-based TypeScript application demonstrating Singleton, Factory and Observer patterns.
Run:
  npm install
  npm run start
Commands (type at prompt):
  add "Description" HH:MM HH:MM Priority
  remove "Description"
  view
  edit "OldDescription" "New Description" HH:MM HH:MM Priority
  complete "Description"
  view-priority Priority
  exit
